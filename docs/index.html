始めるための3手順

インストーラーは不要です。

  1. ZIPを展開

    ダウンロードしたWindows版ZIPを、任意のフォルダーへ展開します。

  2. StoryShelf.exeを起動

    DLLやdataフォルダーを移動せず、そのままの構成で起動してください。

  3. 作品URLを登録

    タイルを作成し、公開中の作品URLを追加すると反応を確認できます。
